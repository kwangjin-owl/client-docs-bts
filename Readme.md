# 시니어 자격증 접수 서비스

두두자격지원센터 접수 서비스입니다. 담당자가 바뀌어도 이 문서만 보면 이어받을 수 있게 적었습니다.

## 화면 다섯 개

| 주소 | 무엇 | 누가 |
|---|---|---|
| `/` | 접수 신청 | 손님 |
| `/check` | 접수 확인 | 손님 |
| `/chat` | 궁금한 것 물어보기 (챗봇) | 손님 |
| `/admin` | 접수 관리 | 직원 |
| `/faq` | 챗봇 답변 관리 | 직원 |

직원용 화면은 비밀번호 `1234` 입니다.

접수 확인은 두 가지로 됩니다. 접수번호로 찾거나, 접수하실 때 넣으신 성함과 연락처로 찾습니다. 어르신이 접수번호를 잃어버리시는 경우가 많아 두 갈래로 두었습니다.

## 파일이 어디에 있나

```
client-docs-bts/
├── index.html            접수 신청
├── settings.json         챗봇 설정 (기준값, 불용어)
├── supabase.sql          데이터베이스 전체
├── admin/index.html      접수 관리
├── chat/index.html       챗봇
├── check/index.html      접수 확인
├── faq/index.html        챗봇 답변 관리
├── api/
│   ├── config.js         Supabase 주소와 키를 브라우저에 전달
│   └── chat.js           Gemini 호출
├── data/                 발주처가 준 원본 자료 (배포 제외)
├── QA/                   QA 체크리스트 기록 (배포 제외)
└── D23_FAQ_챗봇/         실습 과제물, 서비스와 무관 (배포 제외)
```

`api` 폴더에는 서버에서 도는 파일만 넣습니다. 나머지는 전부 맨 위에 두어야 브라우저가 읽습니다.

배포에서 빼는 것은 `.vercelignore` 에 적습니다. 발주처 원본 자료와 접수대장이 여기에 들어 있습니다. **여기서 빼지 않으면 주소만 아는 사람이 그대로 내려받을 수 있습니다.** 새 자료를 받으시면 반드시 이 파일부터 확인해 주십시오.

## 처음부터 다시 만들 때

1. Supabase 에서 새 프로젝트를 만듭니다.
2. SQL Editor 에 `supabase.sql` 을 통째로 붙여넣고 Run 합니다. 표 네 개가 만들어집니다.
3. Table Editor > applications > Insert > Import data from CSV 로 `data/applications_1000.csv` 를 올립니다.
4. Vercel 에 환경변수 세 개를 넣습니다.
   - `SUPABASE_URL`
   - `SUPABASE_ANON_KEY`
   - `GEMINI_API_KEY` (챗봇 AI 를 켤 때만)
5. GitHub 에 푸시하면 자동으로 배포됩니다.

`supabase.sql` 은 여러 번 돌려도 안전합니다. 표가 없으면 만들고 있으면 그대로 둡니다. 쌓인 데이터는 지우지 않습니다. 다만 맨 아래 '싹 지우기' 부분은 주석을 풀면 데이터가 전부 사라지니 손대지 마십시오.

## 표 네 개

| 표 | 무엇 |
|---|---|
| `applications` | 접수 내역 |
| `docs` | 챗봇이 읽는 안내 문서 |
| `questions` | 챗봇이 받은 질문 기록 |
| `synonyms_ko` | 어르신 말 사전 |

Supabase 를 열면 표가 여섯 개 보입니다. **`faq` 와 `synonyms` 는 서비스가 쓰지 않습니다.** 실습 과제(`D23_FAQ_챗봇`)가 만든 것으로, 그 프로그램이 아직 보고 있으니 지우지 마십시오.

헷갈리기 쉬운 것은 `synonyms` 와 `synonyms_ko` 입니다. 이름이 비슷하지만 **서비스가 쓰는 것은 `synonyms_ko` 뿐입니다.** 매핑도 다릅니다. `synonyms` 는 포크레인을 `굴착기` 로 두었고, `synonyms_ko` 는 정식 종목명인 `굴착기운전기능사` 로 둡니다. 동의어를 손보실 때는 반드시 `/faq` 화면을 쓰시고, 표를 직접 고쳐야 한다면 `_ko` 가 붙은 쪽인지 확인해 주십시오.

## 자주 하는 일

### 안내 내용을 고치고 싶을 때

`/faq` 의 **챗봇이 답하는 내용** 탭에서 고치고 저장하면 됩니다. **다시 배포하지 않아도 챗봇 답이 바로 바뀝니다.**

접수 기간이 바뀌었을 때 여기서 고치시면 됩니다.

### 어르신이 쓰는 말을 챗봇이 못 알아들을 때

`/faq` 의 **어르신 말 바꾸기** 탭에서 넣습니다. "포크레인"이라고 물으셔도 굴착기운전기능사 안내가 나오게 하는 곳입니다.

왼쪽에 어르신이 쓰시는 말, 오른쪽에 정식 이름을 넣습니다. **여기도 저장하면 바로 반영됩니다. 깃허브에 푸시하지 않아도 됩니다.**

> 예전에는 `settings.json` 의 `SYNONYMS` 를 고치고 푸시해야 했습니다. 담당자가 바뀌면 손댈 사람이 없어 화면으로 뺐습니다.
>
> **`settings.json` 의 `SYNONYMS` 에 다시 넣지 마십시오.** 사전이 두 곳이 되면 화면에서 지워도 파일에 남은 것이 계속 걸립니다. 목록에서는 사라지고 개수도 줄어드는데 챗봇만 옛날 답을 하기 때문에 알아채기 어렵습니다. 그래서 파일 쪽은 비워 두었습니다. 동의어는 화면 한 곳에서만 관리합니다.

### 챗봇이 엉뚱한 답을 할 때

`settings.json` 을 고치고 깃허브에 푸시합니다.

| 값 | 지금 | 무엇 |
|---|---|---|
| `MIN_SCORE` | `0.35` | 이 점수 아래는 답하지 않습니다 |
| `TOP_K` | `3` | 후보 문서를 몇 개까지 볼지 |
| `TITLE_WEIGHT` | `0.15` | 제목에 걸렸을 때 얹어 주는 점수 |
| `USE_AI` | `true` | 끄면 안내 문서 그대로만 답합니다 |
| `MODEL` | `gemini-3.5-flash-lite` | 쓰는 AI |
| `FALLBACK` | | 답을 못 찾았을 때 나가는 문장 |
| `STOPWORDS` | | 점수에서 빼는 조사와 말끝 |

`MIN_SCORE` 는 올리면 답을 덜 하지만 정확해지고, 내리면 답을 많이 하지만 엉뚱한 답도 늡니다.

**어떤 질문이 안 잡히는지는 `/faq` 의 받은 질문 탭에서 봅니다.** 답함 · 되물음 · 못 찾음 세 가지로 나뉘어 있으니 못 찾음부터 보시면 됩니다. 같은 탭 안에서 바로 안내 문서를 고칠 수 있습니다.

### 자격증을 늘리거나 접수 상태를 바꿀 때

`index.html` 위쪽의 `CERTS` 목록을 고칩니다.

```javascript
{ code:"7910", name:"한식조리기능사", track:"국가기술", agency:"두두넷",
  examType:"상시CBT", fee:14500, state:"now", note:"아무 때나 접수" },
```

`state` 는 세 가지입니다.

| 값 | 화면 표시 |
|---|---|
| `now` | 지금 접수 가능 |
| `soon` | 접수 예정 |
| `late` | 접수 기간 아님 — 고르면 안내가 뜨고 상태가 `문의` 로 저장됩니다 |

## 알아두실 것

### 손님 화면과 직원 화면이 묻는 것이 다릅니다

**손님 화면은 자격증, 성함, 연락처 세 가지만 받습니다.** 발주서에 그렇게 되어 있고, 칸이 많으면 어르신이 중간에 그만두십니다.

나머지는 직원이 `/admin` 에서 채웁니다.

| 갈래 | 자격증 | 직원 화면에서 더 넣는 것 |
|---|---|---|
| 국가기술자격 | 한식조리 · 지게차 · 굴착기 · 전기 | 회차, 응시자격 |
| 전문자격 | 손해평가사 · 공인중개사 | 차수, 과목, 1차 합격번호 |
| 두두보건 | 요양보호사 · 위생사 | 교육기관, 수료번호, 수료일, 이수시간 |

### 표기를 하나로 통일해서 저장합니다

세 기관의 자료가 서로 달라서입니다.

| | 저장 형태 |
|---|---|
| 날짜 | `2026-08-19` |
| 연락처 | `010-0000-0000` |
| 성별 | `M` `F` |
| 결제수단 | 신용카드 / 계좌이체 / 가상계좌 |
| 처리 (`status`) | 접수 / 확인 / 완료 / 취소 / 문의 |
| 결제 (`pay_status`) | 대기 / 완료 / 환불 |
| 접수경로 (`channel`) | 온라인 / 전화 / 방문 / 미기재 |

**처리와 결제는 다른 칸입니다.** 세 기관 CSV 에는 원래 따로 있었는데 한 번 합쳤다가 "접수완료 다음이 결제대기"처럼 순서가 엉켜서 다시 갈랐습니다. 합치지 마십시오.

**연락처는 집 전화도 받습니다.** 접수하신 분의 75%가 70대 이상이라 집 전화만 쓰시는 경우가 있습니다. `0` 으로 시작하는 9~11자리를 모두 받습니다. `010` 만 받으면 안 됩니다.

**접수경로가 `미기재` 인 것은 옛 데이터입니다.** CSV 원본에 접수 경로가 없었습니다. 발주서 1절이 전화 70% · 방문 30% 라고 하니 온라인으로 볼 수 없어 미기재로 두었습니다. 화면으로 들어오는 것만 `온라인` 입니다.

### 접수번호

손님께 알려 드리는 번호입니다. `1MMDD-NNNN-NNN` 모양이고 앞 한 자리가 갈래입니다.

| 앞자리 | 갈래 |
|---|---|
| `1` | 국가기술 |
| `2` | 전문 |
| `3` | 두두보건 |

`20820-0520-450` 이면 전문자격, 8월 20일 접수입니다.

### 접수는 지우지 않습니다

돈이 오간 기록이라 남겨야 합니다. `applications` 표에는 지우는 권한을 아예 넣지 않았습니다.

**잘못 넣으셨으면 처리를 `취소` 로 바꾸십시오.** 화면에 지우기가 없는 것은 고장이 아닙니다.

### 중복 접수 안내에 접수번호를 보여주지 않습니다

이미 접수한 성함과 연락처로 다시 접수하면 안내가 뜹니다. 이때 **접수번호는 보여주지 않고 접수한 날짜만 보여줍니다.** 성함과 연락처만 알면 남의 접수번호를 알 수 있게 되기 때문입니다. 되돌리지 마십시오.

### 모르는 것은 모른다고 답하게 되어 있습니다

챗봇은 `docs` 표에 있는 것만 가지고 답합니다. 없는 것을 물으면 정해진 문장이 나갑니다.

특히 아래 세 가지는 **반드시 모른다고 답해야 합니다.** 발주처가 확인해 주지 않은 것들입니다.

- 위생사 시험 일정
- 상시 종목을 실제로 어디서 신청하는지
- 공인중개사 1차 면제 기간이 정말 1년인지

합격 가능성, 다른 자격증 추천, 실기(2차) 접수도 답하지 않습니다. 저희는 필기 접수까지만 도와드립니다.

안내 내용을 늘리려면 `/faq` 에서 문서를 추가하십시오.

### 말투는 "~해요" 로 맞춥니다

어르신이 읽으시는 글이라 `~해요` 로 씁니다. 새로 넣으실 때도 여기에 맞춰 주십시오. 화면 안내 문구도 같이 맞춰 두었습니다.

다만 안내 문서 2,526개 중 238개는 아직 `~습니다` 로 남아 있습니다. 아래 '아직 못 한 것' 을 봐 주십시오.

발주 문서에 있던 표현을 그대로 옮기면 어르신이 못 알아들으십니다. 예를 들어 "언제 접수하냐가 아니라 언제 자리가 나냐의 문제입니다" 는 "자리가 다 차면 그날은 못 보시니 미리 확인해 주세요" 로 고쳤습니다.

## 아직 못 한 것

- 직원용 화면 비밀번호가 브라우저 코드에 들어 있어 개발자 도구로 볼 수 있습니다. 로그인 기능을 붙여야 제대로 막힙니다.
- 접수 내역 조회 권한이 열려 있어, 주소와 키를 아는 사람은 볼 수 있습니다. `api/config.js` 가 브라우저에 키를 내려 주므로 사실상 누구나 볼 수 있다고 보셔야 합니다. 여기부터 손보는 것이 가장 급합니다.
- 사진 업로드, 주민등록번호, 실명인증, 실제 결제는 넣지 않았습니다.
- 시험장 선택이 지역 단위까지만 됩니다. 시군구와 개별 시험장은 없습니다.
- 안내 문서 238개가 아직 `~습니다` 말투입니다. 상담기록에서 가져온 것은 전부 `~해요` 인 줄 알았는데 그렇지 않았습니다. 규칙으로 답을 찾으면 본문이 그대로 나가므로 어르신께도 `~습니다` 로 나갑니다. 한 가지 형태가 아니라 있습니다 · 없습니다 · 받습니다처럼 제각각이라 한 번에 바꿀 수 없었습니다. 앞말에 따라 `입니다→이에요`, `합니다→해요`, `됩니다→돼요` 로 달라지므로 통째로 치환하면 말이 깨집니다.
  - 남은 수 세기 : `select count(*) from docs where body like '%습니다%'`
  - 어떤 것이 남았는지 : `select id, title, body from docs where body like '%습니다%' limit 50`
