# 시니어 자격증 접수 서비스

두두자격지원센터 접수 서비스입니다. 담당자가 바뀌어도 이 문서만 보면 이어받을 수 있게 적었습니다.

## 화면 네 개

| 주소 | 무엇 | 누가 |
|---|---|---|
| `/` | 접수 화면 | 손님 |
| `/chat` | 문의 챗봇 | 손님 |
| `/admin` | 접수 내역 | 직원 |
| `/faq` | 안내 문서 관리 | 직원 |

직원용 화면은 비밀번호 `1234` 입니다.

## 파일이 어디에 있나

```
client-docs-bts/
├── index.html            접수 화면
├── settings.json         챗봇 설정 (기준값, 비슷한말)
├── supabase.sql          데이터베이스 전체
├── admin/index.html      접수 내역
├── chat/index.html       챗봇
├── faq/index.html        안내 문서 관리
├── api/
│   ├── config.js         Supabase 주소와 키를 브라우저에 전달
│   └── chat.js           Gemini 호출
└── data/                 발주처가 준 원본 자료 (배포에서 제외)
```

`api` 폴더에는 서버에서 도는 파일만 넣습니다. 나머지는 전부 맨 위에 두어야 브라우저가 읽습니다.

## 처음부터 다시 만들 때

1. Supabase에서 새 프로젝트를 만듭니다.
2. SQL Editor 에 `supabase.sql` 을 통째로 붙여넣고 Run 합니다. 표 세 개가 만들어집니다.
3. Table Editor > applications > Insert > Import data from CSV 로 `data/applications_1000.csv` 를 올립니다.
4. Vercel 에 환경변수 세 개를 넣습니다.
   - `SUPABASE_URL`
   - `SUPABASE_ANON_KEY`
   - `GEMINI_API_KEY` (챗봇 AI 를 켤 때만)
5. GitHub 에 푸시하면 자동으로 배포됩니다.

## 자주 하는 일

### 안내 내용을 고치고 싶을 때

`/faq` 에서 고치고 저장하면 됩니다. **다시 배포하지 않아도 챗봇 답이 바로 바뀝니다.**

접수 기간이 바뀌었을 때 여기서 고치시면 됩니다.

### 어르신이 쓰는 말을 챗봇이 못 알아들을 때

`settings.json` 의 `SYNONYMS` 에 넣습니다. 예를 들어 "접수비"로 물어도 "응시료" 답이 나오게 하려면

```json
"응시료": ["접수비", "시험비", "돈", "얼마"]
```

고친 뒤에는 GitHub 에 푸시해야 반영됩니다.

### 챗봇이 엉뚱한 답을 할 때

`settings.json` 의 `MIN_SCORE` 를 올립니다. 지금은 `0.5` 입니다.

- 올리면 답을 덜 하지만 정확해집니다
- 내리면 답을 많이 하지만 엉뚱한 답도 늡니다

**어떤 질문이 안 잡히는지는 `/admin` 아래쪽 "챗봇이 받은 질문"에서 봅니다.** 답을 못 한 질문 목록이 따로 나옵니다.

### 자격증을 늘리거나 접수 상태를 바꿀 때

`index.html` 위쪽의 `CERTS` 목록을 고칩니다.

```javascript
{ code:"7910", name:"한식조리기능사", track:"국가기술", agency:"두두넷",
  examType:"상시CBT", fee:14500, state:"now", note:"아무 때나 접수" },
```

`state` 는 세 가지입니다.

| 값 | 화면 표시 |
|---|---|
| `now` | 지금 접수 가능 |
| `soon` | 접수 예정 |
| `late` | 접수 기간 아님 — 고르면 안내가 뜨고 상태가 `문의` 로 저장됩니다 |

## 알아두실 것

**접수 방식이 세 갈래입니다.** 폼도 그에 맞춰 세 벌로 갈립니다.

| 갈래 | 자격증 | 폼에서 더 묻는 것 |
|---|---|---|
| 국가기술자격 | 한식조리 · 지게차 · 굴착기 · 전기 | 회차, 응시자격 |
| 전문자격 | 손해평가사 · 공인중개사 | 차수, 과목, 1차 합격번호 |
| 두두보건 | 요양보호사 · 위생사 | 교육기관, 수료번호, 수료일, 이수시간 |

**표기를 하나로 통일해서 저장합니다.** 세 기관의 자료가 서로 달라서입니다.

| | 저장 형태 |
|---|---|
| 날짜 | `2026-08-19` |
| 연락처 | `010-0000-0000` |
| 성별 | `M` `F` |
| 결제수단 | 신용카드 / 계좌이체 / 가상계좌 |
| 접수상태 | 접수완료 / 결제대기 / 취소 / 문의 |

**모르는 것은 모른다고 답하게 되어 있습니다.** 챗봇은 `docs` 표에 있는 것만 가지고 답합니다. 없는 것을 물으면 정해진 문장이 나갑니다. 안내 내용을 늘리려면 `/faq` 에서 문서를 추가하십시오.

## 아직 못 한 것

- 직원용 화면 비밀번호가 브라우저 코드에 들어 있어 개발자 도구로 볼 수 있습니다. 로그인 기능을 붙여야 제대로 막힙니다.
- 접수 내역 조회 권한이 열려 있어, 주소와 키를 아는 사람은 볼 수 있습니다.
- 사진 업로드, 주민등록번호, 실명인증, 실제 결제는 넣지 않았습니다.
- 시험장 선택이 지역 단위까지만 됩니다. 시군구와 개별 시험장은 없습니다.
