### M7. 동의어 없이 같은 줄임말로 질문하면 못 찾는다

| 단계 | 내용 |
|---|---|
| 수행 | 동의어 "전기사"를 삭제한 뒤 "전기사 시험비" 입력 |
| 기대 | [NOT_FOUND] 또는 엉뚱한 답변 |
| 확인 | 동의어 유무 차이 기록: [ANSWERED] 전기기능사 필기시험 응시료는 14,500원이고 실기시험은 106,000원입니다. 결제는 큐넷에서 온라인으로 합니다. |
실제:
  "시험비"          → [ANSWERED] 공인중개사 응시료 (자격증 안 물었는데 아무거나 답함)
  "전기사 시험비"   → [ANSWERED] 전기기능사 응시료 (동의어 없이 "시험비"로 걸림)
  "전기기사 응시료" → [UNKNOWN]
원인 확인 (코드로 직접 확인):
  rag.SYNONYMS.get('전기기사') → None       동의어가 앱에 안 읽힘
  _expand_synonyms → "전기기사 응시료"       치환 안 됨
  retrieve → JEONGI_FEE 5점                 검색은 성공
  Gemini → "UNKNOWN"                        전기기사는 전기기능사와 다른 자격증이라 거부
결론: 검색은 됐지만 Gemini가 "근거에 없는 자격증"이라며 답을 거부.
      동의어가 앱 메모리에 안 올라간 것이 원인.
      화면 목록에는 보이는데 rag.SYNONYMS 에는 없음 (DB 읽기와 메모리가 따로 놈)
판정: FAIL
